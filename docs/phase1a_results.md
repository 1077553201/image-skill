# 阶段 1A：蓝色圆盘基础二维结构识别

此文件保留历史专项样例与实测记录。阶段 1G 已将实现迁入 planar_geometry 插件；当前产品定位和通用边界以 architecture.md 与 phase1g_results.md 为准。本报告不表示用户已经确认真实几何。

状态：实现和实测已完成，**等待用户验收**。没有开始 1B、1C 或 3D 建模。阶段 0 已由用户明确验收通过。

## 目标与范围

用 Windows/Python 3.13.11 下已安装的 OpenCV 4.13.0.92 与 NumPy 2.4.4，分离蓝色近正视圆盘，默认选择左侧实例，检测原始外轮廓、近似圆和大型可见背景开口。仅 CPU 运行，没有安装或升级依赖，没有调用 ComfyUI/GPU，没有改动 DGX Spark Conda 环境。

新增 `src/product_photo/extract_structure.py`、`scripts/analyze_product.py`、`tests/test_extract_structure.py` 和本文件；更新 README、架构说明、阶段 0 验收记录与 pyproject 可选依赖声明。新增 `data/intermediate/`，原来的 `data/work/` 等目录保留。

## 最小实现方法

1. 按蓝色 HSV 范围寻找连通外轮廓，依次检查面积、ROI 边界、圆残差、椭圆轴比及角度覆盖。按圆心 x 排序实例，保持每个实例的数据独立。
2. 无法可靠分离的粘连区域明确拒绝，提示完整商品矩形 ROI；ROI 不能恢复被遮挡的真实边界。
3. 在选中商品的实际外轮廓内寻找封闭非蓝区域，按面积占比、中性色证据和离外边界的距离筛选大型开口。不设期望孔数，不使用 `3` 作为算法约束。
4. 保存完整 `CHAIN_APPROX_NONE` 轮廓点。圆拟合只用于摘要和归一化，不用圆替换外轮廓，不把孔简化成圆。
5. 输出原图坐标的 JSON 和四张 PNG；记录参数、运行版本、来源 SHA-256、未分类区域和警告。全部保持未验证状态。

轮廓接口依据：[OpenCV 官方轮廓与形状 API](https://docs.opencv.org/4.13.0/d3/dc0/group__imgproc__shape.html)。

## 已知偏差与限制

1. 外边界不是理想圆。品红拟合圆和绿色观测轮廓存在最多约 5.06 px 的径向差异，这是拟合圆对观测轮廓的误差，不能等同于商品真实几何误差；未强行透视校正。
2. 三个轮廓跟随**白色可见背景开口**，没有把周围暗色内壁全部纳入空洞。特别是上方两孔的侧缘、下方孔的底部，暗色内壁外缘与白色开口边缘明显不同。当前不能作为已验证的前表面加工孔口配置直接建模。
3. `product_mask` 将暗色可见内壁保留为前景；中心小辅助孔尚未抠除。它是阶段 1A 遮罩，不是完整生产抠图。
4. 蓝色近正视、亮中性色背景是当前适用范围。其他颜色、暗背景、强反光、开放边缘缺口或严重透视不保证可靠识别。
5. 白色涂层与背景开口在单图中可能无法区分，必须人工确认候选；面积筛选也不能替代物理类别验证。
6. 置信度是启发式证据分数；外圆约 0.776、三个孔为 0.95，均不代表结构已被物理验证。
