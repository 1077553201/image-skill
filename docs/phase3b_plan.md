# 阶段3B最小质量改进方案

2026-10-15，依据实际3A汇总和lifestyle图：蓝盘出现墙地交线，包袋出现背景纸弯折和旧化灰泥纹理；正面二维前景未改变透视，也没有地面接触阴影，容易与有空间纵深的场景冲突。蓝盘冷色金属与暖色包袋需要不同色调，但不能将素材分类假装成视觉模型识别。

保留3A白底/商业影棚及其执行记录。新增两个可复用配置：abstract_premium（冷调、外围光带、无地平线），editorial_minimal（暖调、外围抽象形态、无背景纸/地面）。两个真实商品各选择一个预设、生成两个不同seed，限四个新增任务。保持原前景、大小、位置、视角及无阴影设置，先比较背景改进，避免同时改变多个变量。

复用现有Provider和合成器，新增小型候选任务/缓存及评价模块。硬约束校验来源、审核、像素/Alpha映射、尺寸/裁切；启发式记录横线、中央边缘密度、轮廓对比度；主观语义检查明确unknown/requires_review。排序仅推荐，不批准资产。全部硬失败/明显风险时显式回退已存在3A影棚，保留失败与备选，无无限重试。
