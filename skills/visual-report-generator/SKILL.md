# 品类视觉报告生成器

基于 Atlas 视觉工作流方法论，为任意跨境电商品类生成标准化的 12 章视觉策略 HTML 报告。

## 核心能力

- **完整方法论**：9大参考模块，覆盖从竞品分析到视觉决策的全链路
- **开箱即用模板**：内置 HTML 模板 + CSS 样式 + Chart.js 图表工具，直接复制使用
- **12章标准结构**：市场分析→关键词→主图→附图→用户洞察→FABE→A+→视频→品牌店→数据诊断→行动计划
- **6种图表类型**：柱状图、横向柱状图、雷达图、环形图/饼图，数据驱动可视化

## 模板资源位置

模板文件位于 `assets/report-template/`，包含：

```
assets/report-template/
├── index.html              # 12章完整HTML模板（含内联图表JS，所有内容用{{占位符}}标记）
└── assets/
    └── report-base.css     # 橙色主题基础样式（设计令牌+全套组件）
```

Chart.js 通过 CDN 加载，图表工具函数已内联在 HTML 中，开箱即用。

**使用方式**：将 `assets/report-template/` 整个目录复制到工作目录，替换 `index.html` 中的 `{{占位符}}` 和底部图表数据即可。

## 报告生成流程

### 第一步：信息收集

在开始生成报告前，收集以下信息：
1. **品类信息**：品类名称（中英文）、目标平台（Amazon/独立站等）
2. **市场数据**：价格带分布、头部品牌列表（至少5个）、各品牌卖点和视觉风格
3. **关键词数据**：核心词/长尾词/场景词及搜索量、竞争度
4. **评论数据**：正面/负面高频词、TOP痛点列表
5. **产品信息**：本产品的特性、优势、目标用户定位

如果用户未提供完整数据，基于品类常识和市场通用情况生成合理的占位分析，并标注"需根据实际数据验证"。

### 第二步：生成报告

1. 复制 `assets/report-template/` 到工作目录
2. 按章节顺序替换 `index.html` 中的 `{{占位符}}` 内容
3. 替换底部 `<script>` 中的图表数据
4. 确保所有 12 个章节内容完整填充
5. 使用 `create_html` 工具部署为可访问的在线页面

### 第三步：质量检查

交付前确认：
- [ ] 12个章节全部填充，无遗漏 `{{占位符}}`
- [ ] 6张图表数据已替换为对应品类数据
- [ ] 核心洞察和策略建议具体、可落地
- [ ] FABE矩阵至少包含5个完整卖点链
- [ ] 行动计划有明确优先级和时间线
- [ ] 报告语言为中文，专业、简洁

## 图表工具使用

`report-charts.js` 封装了4种常用图表，调用方式：

```javascript
// 柱状图
ReportCharts.bar({ canvasId, labels, datasets, title });

// 横向柱状图
ReportCharts.horizontalBar({ canvasId, labels, datasets, title });

// 雷达图
ReportCharts.radar({ canvasId, labels, datasets, title });

// 环形图/饼图
ReportCharts.doughnut({ canvasId, labels, data, title });
```

所有图表默认使用橙色主题，自动响应式。

## 执行原则

1. **先研究再输出**——不要凭空生成，尽量基于品类常识和市场规律
2. **数据可替换**——所有数据用变量/占位符思维组织，方便用户替换
3. **策略可落地**——每个策略建议都要有具体做法，不要空泛
4. **完整闭环**——从分析到策略到行动计划，形成完整闭环
5. **视觉专业**——充分利用模板的卡片、表格、洞察框、图表等组件，保证视觉质量
