# 用户洞察方法论

页面优化之前，先理解用户。很多页面的问题，不是设计不努力，而是用户不在场。

## 用户洞察的六个核心维度

做视觉前，至少要回答这六个问题：

| 维度 | 问题 | 决定什么 |
|------|------|---------|
| 1. 人群 | 谁在买？年龄、性别、经验、消费能力、审美偏好是什么？ | 视觉风格、模特选择、文案语气 |
| 2. 场景 | 什么时候用？在哪用？和谁一起用？ | 场景图方向、使用状态展示 |
| 3. 动机 | 为什么现在想买？是解决问题、提升效率、表达身份，还是满足情绪？ | 核心卖点排序 |
| 4. 痛点 | 当前最不满意的是什么？ | 问题图、对比图方向 |
| 5. 痒点 | 不是刚需，但会让人更想买的是什么？ | 情绪价值、溢价空间 |
| 6. 决策触发点 | 什么信息最容易推动他下单？ | 证据图、FAQ内容 |

这六个问题决定了页面该讲什么、先讲什么、重点讲什么。

---

## 五层次需求：痛点→痒点→爽点→燃点→爆点

| 层次 | 定义 | 对应页面模块 |
|------|------|-------------|
| **痛点** | 消费者在生活或工作中所遭遇的困扰难题以及尚未被满足的需求 | 问题图、对比图 |
| **痒点** | 在基本需求之上，消费者对美好生活、高品质体验等方面的潜在渴望，属于"想要却并非必要" | 卖点图、场景图 |
| **爽点** | 用户在使用产品时，因问题得以迅速解决或者获得超出预期的体验，而产生的即时且强烈的愉悦感和满足感 | 证据图、使用过程 |
| **燃点** | 能够激发用户内心激情，与用户的价值观、信仰、梦想等深层次情感因素相关联，引发强烈情感共鸣 | 品牌主张、场景代入 |
| **爆点** | 在短时间内迅速走红，获得大量关注与传播，进而突破原有受众局限，提升品牌知名度和市场份额 | 品牌记忆点、传播钩子 |

> 这五种点不一定平均分配，但它们能帮助理解：附图不是纯信息堆叠，而是**理性与情绪一起推动决策**。

## 用户为什么点进去（点击心理）

主图背后的四个心理机制：
1. **快速识别** — 这是什么？是不是我在找的东西？
2. **快速区分** — 这个和别的有什么不一样？
3. **快速信任** — 这个看起来靠谱吗？
4. **快速吸引** — 这个看起来有点意思/有点想要

---

## 用户为什么继续看页面（浏览深度）

用户进入页面后的心理路径：
1. **3-5秒快速扫前几张图** — 判断有没有继续看的必要，决定是否停留
2. **10-20秒寻找核心卖点** — 想知道和别人的差别，建立产品认知
3. **20-40秒寻找信任证据** — 想确认这不是"说得好听"，建立信任感
4. **回到价格、评价、购买区** — 做最终平衡判断，决定是否购买

> 页面不是"从上到下介绍产品"，而是要围绕用户的决策路径去安排内容节奏。

---

## 用户为什么最终下单（成交四因）

成交拆成更底层的四个原因：
1. **需求匹配** — 这东西确实能解决我的问题
2. **差异感知** — 你比别的更适合我/更好
3. **信任建立** — 我相信你说的是真的
4. **行动推动** — 现在买是合适的时机

---

## 卖点转译：从"产品有什么"到"用户能得到什么"

很多页面的问题，不是没卖点，而是卖点没有被翻译成用户听得懂、感受得到的话。

### 转译原则

| 错误方式 | 正确方式 |
|---------|---------|
| 只讲产品参数："采用航空级铝合金材质" | 讲使用结果："更轻更耐用，长时间使用不累手" |
| 只讲功能优势："我们的电机功率更大" | 讲用户利益："升降更平稳，桌面物品不会晃动" |
| 只讲感受："穿着非常舒适" | 讲证据："面料透气测试报告 + 10000+好评验证" |
| 只讲"我们很好"："我们是行业领先品牌" | 讲"为什么值得你选"："10年专注 + 500万用户选择 + 专利技术" |

> 核心：内容营销的核心不是介绍产品，而是翻译价值——把产品语言翻译成用户能感知的利益语言。

## 评论区反推内容法

评论区不是售后区，而是最真实的内容策划输入源。

### 三类评论 → 三类内容模块

| 评论类型 | 告诉你什么 | 转译内容 |
|---------|-----------|---------|
| **差评** | 用户最担心什么、最容易踩坑什么 | 尺寸对比图、防漏展示图、噪音说明 |
| **好评** | 用户觉得最值、最爽的点是什么 | 材质特写图、使用效果展示、场景代入 |
| **中性评论/FAQ** | 用户理解门槛在哪里 | 安装步骤图、使用说明、兼容列表 |

### 实操方法

1. 收集至少50-100条评论（好评+差评+QA）
2. 按"购买动机/满意点/不满点/场景词/高频问题"分类
3. 统计每类出现频次
4. 高频问题 → 对应到页面模块（附图第几张放、A+哪个模块讲）
5. 结果：把这些信息整理出来后，附图标题和内容方向会清晰很多

> 如果你不知道页面该讲什么，最值得去看的地方之一就是评论区。

## 价值主张画布

借助产品价值主张画布 → 匹配用户真实需求：

**产品侧（我们提供什么）：**
- 产品与服务
- 痛点缓解方案
- 收益创造方案

**用户侧（用户想要什么）：**
- 用户画像（人群、场景、任务）
- 用户痛点（担心、失望、障碍）
- 用户收益（期望、需求、想要的结果）

核心方法：
1. 了解客户真正需求
2. 设计相应的解决方案
3. 确保产品与市场需求相匹配

## 亚马逊各代际消费者特征（参考）

| 代际 | 出生年份 | 购物特征 | 视觉偏好 |
|------|---------|---------|---------|
| Z世代 | 1997-2012 | 省钱意识强、重视评论、视频和社交广告参与度高、AR接受度高 | 短视频、社交感、个性化、科技感 |
| 千禧一代 | 1981-1996 | 冲动消费高、受社媒影响、容易跳过广告、站外广告引流多 | 生活方式、体验感、品牌价值观 |
| X世代 | 1965-1980 | 价格敏感、时间意识强、决策独立、注重产品质量、品牌忠诚度高 | 功能清晰、质量证据、对比明确 |
| 婴儿潮一代 | 1946-1964 | 价值驱动、重视质量可靠性、品牌忠诚、传统购物习惯 | 大字体、高对比、清晰按钮、信任证据 |
| 沉默一代 | 1928-1945 | 节俭、忠诚、保守、重视实用性和耐用性、对广告怀疑 | 简洁直接、家庭/社区价值观、品质保证 |

> 注：以上为通用参考，具体类目需结合实际用户画像调整。
