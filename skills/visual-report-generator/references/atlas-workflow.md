# Atlas 视觉工作流（10步）

从竞品分析到视觉决策的系统方法。核心认知：这不是单纯的设计流程，而是**市场信息抓取 + 用户洞察 + 视觉决策**的完整链路。

## 工作流目标：回答5个核心问题

1. **这个类目现在是怎么卖的**——理解市场主流表达方式和竞争格局
2. **用户为什么会点、会买、会退**——洞察真实购买动机和决策顾虑
3. **市场视觉已经卷到哪里了**——识别同质化程度和差异化机会
4. **我的产品该占哪个表达位置**——确定差异化定位
5. **最终主图、附图、A+应该怎么做**——更准确地转化目标用户

---

## 第0-1步：定义研究对象

### 定义研究对象的4个要素

1. **核心主关键词** — 例如：portable blender
2. **次级关键词** — personal blender / smoothie blender / travel blender / rechargeable blender
3. **竞品采样范围**（分层抽样，共约70个样本）：
   - 前20名头部款
   - 20个中腰部款
   - 10个高价品牌款
   - 10个低价跑量款
   - 10个视觉风格差异款
4. **要研究的页面模块**：搜索结果页、商品标题、主图、五点、附图、A+、评论、Q&A、品牌店铺

### 适用与不适用

**适合做**：搜索结果页分析、Listing拆解、评论高频词提炼、Q&A疑虑提炼、品牌表达对比、输出结构化洞察与视觉建议

**不适合做**：广告后台历史报表清洗、多周期经营数据建模、大批量CSV拉数分析

---

## 第2步：竞品关键词与标题分析

这是整个视觉工作的入口。

### 分析维度

| 维度 | 要回答的问题 | 输出 |
|------|-------------|------|
| 高频词分类 | 这些词属于什么类型？功能词/场景词/人群词/风格词/情绪词 | 市场共识词汇表 |
| 头部重复表达 | 哪些表达在头部商品里重复最多？ | 市场主流表达 |
| 用户动机词 | 哪些词代表用户核心购买动机？ | 差异化利益点 |
| 类目基础描述 | 哪些词只是类目基础描述？ | 真正的差异化机会 |

### 三层输出

1. **市场共识** — 这个类目正在卖什么（如 portable / rechargeable / smoothie / USB-C）
2. **用户入口** — 用户真正在买什么（如 on-the-go / protein shakes / gym / travel）
3. **视觉表达方向** — 视觉应该偏向什么风格
   - 高频词是 powerful / crushes ice → 视觉偏性能感
   - 高频词是 easy clean / travel-friendly → 视觉偏便携与生活方式

> **关键洞察**：标题分析不是看"哪个词出现最多"，而是看这些词背后代表的用户需求层次。

---

## 第3步：主图共性分析

视觉团队最关键的一层。

### 抓取维度

- 画面类型：白底纯产品 / 人模拿产品 / 场景化合成
- 展示方式：单体展示 / 套装展示 / 配件齐全型
- 画面重心：产品外观 / 使用结果（如果昔成品）
- 强调元素：刀片、马达、容量、颜色
- 是否有功能icon
- 风格偏向：品牌感 / 信息密集型电商风
- 价格带差异：高价款和低价款视觉有什么差异
- 同质化程度：哪些主图点击逻辑已经高度同质化

### 三层输出

1. **主流点击模型**（A/B/C分类）
   - A类：白底 + 产品 + 配件齐全
   - B类：白底 + 使用结果展示 + 颜色鲜艳
   - C类：人手握持 + 强调便携与场景
2. **类目审美偏向** — 工具感 / 家居感 / 健康感 / 科技感 / 礼品感
3. **差异化机会点** — 市场都在讲什么，但很少讲什么

> 最后拿到的不是"大家都长什么样"，而是**主流点击模型 + 类目审美偏向 + 差异化机会点**。

---

## 第4步：附图与A+结构分析

从"吸引点击"走向"说服购买"。

### 附图分析要点

- 附图数量分布
- 每张图在讲什么：性能/场景/人群/清洗/容量与配件
- 最常见的"说服顺序"是什么
- 这个顺序真的合理吗？还是大家只是彼此模仿？

### A+分析要点

- A+是偏品牌叙事还是偏功能对比
- 表达重心在哪里
- 头部品牌 vs 普通卖家的差异

> **常见陷阱**：很多页面只是把附图再重复一遍；头部品牌会更多强调生活方式和品牌感。

---

## 第5步：评论与Q&A用户洞察

这一步决定后面的视觉到底准不准。

### 评论要抓4类词

| 类别 | 说明 | 作用 |
|------|------|------|
| 购买动机词 | 用户为什么买 | 找到核心卖点 |
| 满意点词 | 用户真正喜欢的点 | 强化优势表达 |
| 不满点词 | 用户最容易失望的地方 | 提前消除顾虑 |
| 场景词 | 真正的使用场景 | 场景图方向 |

### Q&A要抓"下单前犹豫"

这些问题直接对应附图该补什么信息：
- Can it crush ice? → 需要展示打冰能力
- Will it leak in a backpack? → 需要展示防漏设计
- How long does the battery last? → 需要展示续航信息

> **关键洞察**：到这一步，真正有价值的不是"评论里有这些词"，而是你要**翻译成结论**。

---

## 第6-7步：用户画像与表达站位

### 第6步：做"购买决策型画像"

不要做空泛画像，要做基于购买决策的分层画像。例如：

| 画像类型 | 核心需求 | 看重点 | 喜欢的视觉 |
|---------|---------|--------|-----------|
| 健身补给型 | 快速打蛋白、随身携带 | 便携、续航、密封、防漏 | 简洁利落、运动场景、效率感 |
| 办公室健康型 | 上班时快速喝果昔/代餐 | 清洗方便、桌面友好、不吵、颜值高 | 极简、干净、轻生活方式 |
| 出行轻食型 | 旅行、露营、酒店使用 | 体积小、无线、可带走、稳定 | 旅行感、户外感、场景化 |
| 性能在意型 | 真能打冰、打冻果 | 刀片、马达、功率表现 | 结构感、性能对比、结果展示 |

### 第7步：确定"表达站位"

核心问题：**你不能简单问"我的产品有什么卖点"，而是要问：在这个市场里，我的产品应该占哪个表达位置？**

判断四问：
1. 我的产品强项是什么？
2. 市场都在讲什么？
3. 哪些点已经太卷？
4. 我能占哪个认知位？

> 到这里，你已经不再是"为所有人做图"，而是知道要先抓谁。

---

## 第8步：翻译成视觉策略

把前面的结果翻译成6个视觉动作：

| 维度 | 决策内容 |
|------|---------|
| 1. 主图策略 | 先抢什么注意力？性能还是场景？产品本体还是使用结果？ |
| 2. 附图顺序 | 第一张先讲什么？第二张补什么？第三张打什么？最后如何收尾？ |
| 3. 模特/场景方向 | 需不需要真人？是办公室、健身房、车里还是旅行场景？场景要不要极简？ |
| 4. 信息密度 | 走简洁品牌感还是高信息密度？类目是否接受大量功能icon？ |
| 5. 文案语气 | 更像科技产品/生活方式品牌/实用工具/健康消费品？ |
| 6. A+叙事方式 | 强调品牌理念/使用体验/对比与选择/场景融合？ |

> 到这里，工作基本从"研究"进入"决策辅助"。

---

## 第9-10步：辅助设计与上线复盘

### 第9步：辅助设计执行

角色变成"校对与验证"，检查：
- 主图是不是已经和类目同质化
- 附图是否覆盖了评论里最高频的担忧
- 文案有没有在说用户真正关心的利益点
- A+是不是重复附图，而不是补充说服
- 页面有没有承诺超过产品真实能力

### 第10步：上线后复盘

观察指标与解读：
- **CTR是否变化** → 主图改了CTR升了 = 入口对了
- **CVR是否变化** → CTR升了CVR没升 = 详情页没接住
- **新评论是否更集中提到你强调的点** → 表达和真实购买理由对上了
- **新Q&A是否减少了原本的疑虑** → 信息补位有效
- **差评是否从某些问题上下降** → 对应痛点解决了

> **核心认知**：这是一条持续迭代的工作流，不是一次性的任务。

---

## 团队分工与执行方式

| 角色 | 负责内容 |
|------|---------|
| 策划/运营 | 主关键词与采样竞品清单、页面抓取、评论Q&A信息整理 |
| 视觉策划 | 从洞察提炼主图逻辑、附图顺序、场景表达；明确模特/道具/构图方向 |
| 设计师 | 具体页面产出、版式和视觉统一 |
| 负责人 | 最终判断"表达站位"是否正确、是否与产品真实能力一致、是否有差异化机会 |

## 核心记忆点

用Atlas先看市场怎么讲，再看用户为什么买，再决定自己该怎么讲，最后再拿页面与数据去验证。

**竞品分析 → 关键词共性 → 主图共性 → 附图结构 → 评论/Q&A洞察 → 用户画像 → 表达站位 → 视觉策略 → 页面产出 → 上线复盘**
