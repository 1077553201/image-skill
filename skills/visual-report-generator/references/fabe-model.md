# FABE 卖点转译模型

把卖点从产品语言翻译成成交语言。FABE非常适合作为跨部门共用语言，让产品、市场、运营、视觉团队在同一套逻辑下协作。

## FABE 四要素

| 字母 | 全称 | 含义 | 说明 |
|------|------|------|------|
| **F** | Features 特性 | 产品功能特点、产品特性清单 | 产品有什么 |
| **A** | Advantages 优势 | 对比同类竞品、对比原有版本、针对行业痛点 | 比别人好在哪 |
| **B** | Benefits 实际利益 | 用户能得到的具体好处 | 对我有什么用 |
| **E** | Evidence 证据 | 权威证明、实验数据、用户反馈、销量证明 | 凭什么相信 |

> **核心洞察**：F + A 很多页面做到了，但真正拉动转化的是 B + E。

---

## 为什么只讲F和A不够打动人

只讲F和A的页面：
- 很专业（参数详细，技术性强）
- 很完整（功能罗列全面）
- 很像说明书（缺乏情感共鸣）
- 但不够打动人（用户看完没感觉）

### 原因：用户不会自动帮你完成翻译

| 产品语言 | 用户语言（需要翻译） |
|---------|-------------------|
| 高密度海绵坐垫 | 坐更久也不容易累 |
| 升级悬挂系统 | 路不平时更稳、更安心 |
| 航空级铝合金材质 | 更轻更耐用，长时间使用不累手 |
| 更大功率电机 | 升降更平稳，桌面物品不会晃动 |

如果没有利益点和证据，很多优势就只是品牌自己说得好听。

---

## Benefits（利益点）的10种类型

1. **功能性利益** — 解决具体问题、达成具体结果
2. **经济性利益** — 省钱、划算、性价比高
3. **稀缺性利益** — 限量、独家、限时
4. **社交性利益** — 身份象征、社交货币、群体认同
5. **情感性利益** — 快乐、安心、满足感、成就感
6. **社会性利益** — 环保、公益、社会责任
7. **个性化利益** — 定制化、专属感、与众不同
8. **风险规避利益** — 安全、保障、减少损失、售后无忧
9. **自我实现利益** — 成长、进步、达成目标
10. **便利性利益** — 省时、省力、简单易用
11. **时间性价值** — 更快、更早、效率提升

---

## Evidence（证据）的常见形式

1. **权威机构证明** — 认证、检测报告、奖项
2. **详细实验数据** — 对比测试、性能参数、使用寿命
3. **真实用户反馈** — 好评截图、用户证言、UGC内容
4. **实际销量证明** — 销量数字、热销排名、用户数量
5. **结构/工艺展示** — 拆解图、剖面图、工艺细节
6. **前后对比** — 使用前后效果对比、与竞品对比
7. **品牌背书** — 品牌历史、合作机构、专家推荐
8. **服务保障** — 质保、退换货政策、售后承诺

## FABE 三种结构打法

### 一、基本型结构（技术驱动型）— FABE

**顺序**：Features → Advantages → Benefits → Evidence

**适用场景**：
- 3C数码、家电、工具类等技术驱动型产品
- 需要建立专业权威感的类目
- 用户决策偏理性、看重参数和性能

**特点**：先讲功能，再讲优势，再讲利益，最后给证据。逻辑递进清晰，专业感强。

---

### 二、感性型结构（情感驱动型）— BFEA

**顺序**：Benefits → Features → Evidence → Advantages

**适用场景**：
- 服饰、美妆、家居等情感驱动型产品
- 需要构建情感账户的类目
- 用户决策偏感性、看重体验和感受

**特点**：先抛利益点抓住注意力，再讲功能支撑，给证据，最后补优势。情绪先行，理性收尾。

---

### 三、挑剔型结构（防御反击型）— AEFB

**顺序**：Advantages → Evidence → Features → Benefits

**适用场景**：
- 竞争激烈、用户对比多的类目
- 需要对抗性谈判/对比的场景
- 用户决策谨慎、挑剔

**特点**：先亮差异，再给证据，再讲功能，最后讲利益。适合竞品对比激烈的环境，先建立"我不一样"的认知。

## FABE 实战案例

### 案例1：塑形衣（Shapewear）

| 要素 | 内容 |
|------|------|
| **F 特性** | 高弹力塑形面料 |
| **A 优势** | 更贴合身形，不容易卷边，支撑更稳定 |
| **B 利益** | 穿着更舒服，收腹更自然，日常穿也不容易勒得难受 |
| **E 证据** | 面料结构图、穿着前后对比、用户评价、细节放大图 |

---

### 案例2：童车（Kids Electric Vehicle）

| 要素 | 内容 |
|------|------|
| **F 特性** | （动力系统相关） |
| **A 优势** | 动力更足，起步更稳，适应更多路面情况 |
| **B 利益** | 孩子开起来更顺畅，家长更放心，整体体验更高级 |
| **E 证据** | 动力结构示意、场景视频、路况实拍、用户反馈 |

---

### 案例3：升降桌（Standing Desk）

| 要素 | 内容 |
|------|------|
| **F 特性** | 双电机升降系统 |
| **A 优势** | 升降更平稳、承重更强、噪音更低 |
| **B 利益** | 工作切换更顺滑，长时间使用更舒适，桌面体验更高级 |
| **E 证据** | 电机结构图、稳定性演示、分贝对比、真实使用视频 |

> 这说明FABE不是服饰专属，而是适合多类目的底层表达方法。

---

## FABE 小结

先记住：**用户不是买功能，而是买结果和确定性**。

FABE最重要的，不是记住四个字母，而是记住这件事：
- **功能**只是起点
- **优势**只是差异
- **利益**才会让用户觉得"和我有关"
- **证据**才会让用户敢下单
