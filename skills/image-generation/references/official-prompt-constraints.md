# 官方提示词约束

来源核查：2026-10-16。这里只保存官方指南中适用于本 Skill 的方法提炼和链接，不收集社区案例、商品参数或案例卡。它们用于改善表达和检查，不证明当前模型、节点或商品结果已通过验证；具体接口能力仍以执行环境为准。

## OpenAI：职责清楚、保留项明确、逐步修正

来源：[Image prompting](https://developers.openai.com/api/docs/guides/image-prompting)、[图像生成提示指南及商品示例](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)。

- 按主体、场景、构图、细节和约束描述结果；写清用途、画布比例与关键位置，避免只堆质量形容词。
- 按上传编号说明每张输入图提供什么，例如商品身份、人物、服装、风格或背景，以及如何组合。风格参考不能覆盖身份参考。
- 编辑时拆开“只改变什么”和“保持什么”；局部修正后核查其余区域是否漂移，不假定多次编辑天然一致。
- 商品抠图或合成检查轮廓、标签与边缘；需要透明时同时使用工具支持的透明设置和保留透明度的格式，并检查实际 alpha 通道。
- 要求像素不变的区域，应保留原始像素并合成；提示词本身不能保证这一点。

本 Skill 仍将新增营销文字交给真实字体排版。官方直接绘字的示例不改变这个制作约定，也不代表商品标签已准确保留。

## Google：商业摄影、明确留白与局部编辑

来源：[Gemini 图像生成指南](https://ai.google.dev/gemini-api/docs/image-generation)，参见商品摄影、留白设计、局部编辑与多图组合章节。

- 商品摄影明确背景表面、光源及目的、相机角度、要展示的已知细节与比例，使光影服务于本页重点。
- 为后续排字说明主体落点、留白方位、背景颜色和留白范围；“留白”应落实到画面位置，实际生成后仍要核对。
- 多图组合明确从哪张图取哪个元素、放到哪里；检查比例、接触、光影和透视关系，不只说“融合参考图”。
- 局部编辑指定仅修改的元素，同时列出原图需要保留的光影、风格与构图。工具没有精确编辑能力时不假装支持。

官方示例中的材质、蒸汽、使用环境等都是示例输入；只有当前商品资料或用户确认支持的内容才能复用。

## Qwen：按区域描述，保持空间与光影关系

来源：[Qwen-Image 2.1 官方提示词重写模板](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/prompt_rewrite/prompts/system_prompt_t2i.txt)。

- 先分清用户已固定的内容与可以设计的画面内容，锁定已确认对象、数量、颜色与位置。
- 将复杂页面按背景、上部、主体区与下部描述；单主体按整体、表面、接触关系和边缘描述，保持对象可定位。
- 写清光源方向、光质、阴影与反射，检查相邻物品比例和接触关系是否一致。
- 无须读字的区域不发明标语或装饰文字；新增营销文案只保存在排版数据中。

不能直接套用原模板要求的“补全一切未说明内容”、固定长篇幅、猜测材质或改写成含糊候选。未知商品事实必须追问或经用户确认省略；装饰、背景和人物创意仅在用户批准的范围内补充。不照搬其输出字段、英文要求或默认比例到不兼容的工作流。

## 使用方式

编写提示词时只选当前任务需要的方法，并在执行记录中简要写明采用了哪项约束。提示词中的商品内容以已确认资料和参考图为准；本文件不提供任何商品事实。实际尺寸、参考图数量、编辑或透明能力在提交前验证，不依赖这里保存的静态规则。
